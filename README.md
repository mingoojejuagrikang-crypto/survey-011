## 설치와 첫 사용

1. 스마트폰 Chrome에서 위 배포 URL에 접속합니다.
2. 메뉴 → **홈 화면에 추가**로 PWA를 설치합니다.
3. **설정 탭** → Google 로그인 → 스프레드시트 URL 붙여넣기
4. 컬럼 카드에서 각 항목의 **데이터형·입력방식**을 조정합니다.
5. `오늘 테이블 생성`을 누릅니다.
6. **입력 탭** → 이어폰 착용 → `음성 입력 시작`
7. TTS 안내를 듣고 값을 말하면 자동으로 다음 항목·행으로 진행합니다.

세로 화면 전용입니다(가로로 돌리면 "세로로 돌려주세요" 안내가 뜹니다).

## 기능

- **설정** — Google OAuth 로그인 → 스프레드시트 URL → 컬럼 자동 분석 → 데이터형/입력방식 설정 → 오늘 테이블 생성
- **입력** — 항상 켜진 마이크 + TTS 안내 + 자동 행 진행 + Wake Lock(화면 꺼짐 방지) + 이상치 추세 경보
- **데이터** — IndexedDB 영속화 + Google Sheets 자동 동기화 + CSV/ZIP 내보내기 + 음성 클립 재생
- **개선요청** — 화면 캡처와 로그를 첨부해 바로 보낼 수 있는 피드백 탭
- **오프라인 내성** — 네트워크·로그인이 끊겨도 기록과 경보는 계속 동작하고, 복구되면 큐가 올라갑니다

## 음성 명령

> **기능당 한 단어**입니다(v0.4.0부터 별칭 없음). 입력 화면의 **`？명령어`** 버튼이나
> **"도움말"** 발화로 전체 목록을 볼 수 있습니다.
> 아래 표의 SSOT는 [`src/lib/voiceCommands.ts`](./src/lib/voiceCommands.ts)입니다.

| 키워드 | 동작 |
|--------|------|
| 숫자 | 현재 항목에 입력 (한글 수사·아라비아 모두 지원) |
| `수정` (+ 값) | 직전에 입력한 값을 고침 (`178.1 수정`처럼 값 뒤에 붙여도 됨) |
| `수정` + 항목 이름 | 행 값을 읽어준 뒤·이미 채운 칸에 돌아가 있을 때·마지막 행 끝에서, 앱이 읽어주는 이름 그대로(`수정 종경`) 그 **칸 하나만** 다시 받음. 이름이 같은 항목이 둘 이상이면 「첫 번째 …인가요, 두 번째 …인가요?」로 물음(v0.52) |
| `이전` / `다음` | 값 입력 없이 바로 앞/뒤 **항목**으로 이동 |
| `이전행` / `다음행` | 이전/다음 **행**으로 이동 (완료 행은 값을 읽어주고 대기 · 입력 중이던 행은 빈 행으로 남아 데이터 탭에서 채울 수 있음) |
| `취소` | 현재 인식된 값을 지움 |
| `유지` | 현재 항목의 값을 그대로 두고 다음으로 진행 |
| `확인` | 추세 경보에서 방금 입력한 값을 그대로 확정 |
| `일시정지` / `재시작` | 입력 멈춤 / 재개 |
| `종료` | 입력을 끝내고 저장 |
| `도움말` | 음성 명령어 도움말 열기 (닫기는 손으로만) |
| `화면` | 화면만 끄고 음성 입력은 계속 (다시 켜기: 검은 화면 가운데를 2초) |

> 🔴 **v0.51에서 조절판 음성 명령 5종을 없앴습니다**(민구 확정 2026-08-31) —
> `입력조절` · `인식률낮추기/높이기` · `안내속도느리게/빠르게`.
> **기능이 사라진 게 아니라 「손으로만」이 됐습니다**: 입력 화면 하단의 요약 필을 눌러
> 조절판을 열고 `−` `+` 로 조절합니다. 이유는 이 명령들이 필요한 순간이 곧 **인식이 안 되는
> 순간**이라 명령 자체가 인식 문턱(0.7)을 넘기 어렵고, 결과(%)도 조절판을 봐야 알기 때문입니다.

"이전행"·"다음행"처럼 뒤에 말을 붙여도 앞부분으로 인식됩니다.

한국어 수사 예시: `삼십오 점 일` → `35.1`, `일점오` → `1.5`, `이천이십육` → `2026`

## 코드 구조 (개요)

```text
src/
├── components/     화면별 표현 컴포넌트 (voice/ settings/ data/ + 공용)
├── screens/        설정·음성입력·데이터 화면
├── stores/         Zustand 상태와 영속화 경계
```
